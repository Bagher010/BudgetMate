# BudgetMate

BudgetMate is an Android personal-finance app built with Kotlin, Jetpack Compose, and Room. This repository contains the app source and resources.

## Build

Open the project in Android Studio, or run `./gradlew bundleStandardRelease` with the Android SDK installed. Configure upload signing through the `BUDGETMATE_UPLOAD_*` environment variables when producing a Play upload bundle. Do not commit signing keys or credentials.

The application ID is `com.budgetmate`. Finance records are stored locally on the device.
